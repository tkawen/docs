## English

Runnable examples live in the monorepo under [`examples/`](https://github.com/tkawen/packages/tree/main/examples).

| Example | Stack | Shows |
| --- | --- | --- |
| [mystoq-node-quickstart](https://github.com/tkawen/packages/tree/main/examples/mystoq-node-quickstart) | Node.js | List wilayas/products and create a cash-on-delivery order with `@tkawen/mystoq-sdk` |
| [liqaa-web-widget](https://github.com/tkawen/packages/tree/main/examples/liqaa-web-widget) | Browser / HTML | Add an instant video-call button with `@tkawen/liqaa-js` |

```bash
# Mystoq quickstart
npm install
MYSTOQ_API_KEY=sk_live_xxx MYSTOQ_TENANT=demo npm start
```
