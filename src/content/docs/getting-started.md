## English

All TKAWEN libraries live under the **`@tkawen`** npm organisation and the single open-source monorepo [`tkawen/packages`](https://github.com/tkawen/packages).

```bash
npm install @tkawen/mystoq-sdk
```

| Package | Install |
| --- | --- |
| `@tkawen/mystoq-sdk` | `npm i @tkawen/mystoq-sdk` |
| `@tkawen/mystoq-react` | `npm i @tkawen/mystoq-react` |
| `@tkawen/mystoq-mcp-server` | `npm i @tkawen/mystoq-mcp-server` |
| `@tkawen/mystoq-seo-toolkit` | `npm i @tkawen/mystoq-seo-toolkit` |
| `@tkawen/mystoq-maystro-bridge` | `npm i @tkawen/mystoq-maystro-bridge` |
| `@tkawen/mystoq-whatsapp-bridge` | `npm i @tkawen/mystoq-whatsapp-bridge` |
| `@tkawen/mystoq-yalidine-bridge` | `npm i @tkawen/mystoq-yalidine-bridge` |
| `@tkawen/liqaa-js` | `npm i @tkawen/liqaa-js` |
| `@tkawen/liqaa-react` | `npm i @tkawen/liqaa-react` |

## عربي

كل مكتبات تكوّن تحت منظّمة **`@tkawen`** على npm، وفي مستودع مفتوح المصدر واحد [`tkawen/packages`](https://github.com/tkawen/packages). ثبّت أي حزمة بـ `npm i @tkawen/<الاسم>`.
